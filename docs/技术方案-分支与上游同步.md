## 分支职责

| 分支 | 职责 |
|---|---|
| **`hjsmaster`** | 交付主线：Docker 镜像、QNAP、NPM `/sublink/` |
| **`hjs-feature`** | 唯一开发分支（含子路径扩展） |
| **`upstream/main`** | 上游 main，只 fetch |

## 远程

```bash
git remote add upstream https://github.com/7Sageer/sublink-worker.git  # 若未添加
git fetch upstream
```

## HouJia 差异（合并时保留）

| 路径 | 内容 |
|---|---|
| `src/runtime/basePath.js` | `BASE_PATH` 默认 `/sublink`、`wrapFetch` |
| `fork/docker/` | Dockerfile、compose |
| `fork/docs/nginx-subpath.example.conf` | NPM 片段 |
| `.env.example` | 子路径与环境变量模板 |

## 同步上游

```bash
git checkout hjs-feature
git merge upstream/main
npm test && npm run build:node
git push origin hjs-feature
git checkout hjsmaster && git merge hjs-feature && git push origin hjsmaster
```

## NAS 部署

```bash
cd fork/docker
docker compose -f docker-compose.fork.yml up -d --build
curl -sI http://127.0.0.1:58087/sublink/
```

**端口**：QNAP 上 NPM 访问 `8787` 可能失败，compose 已映射 **58087:8787**。

NPM：见 `fork/docs/npm-server_proxy.snippet.conf`（`proxy_pass` 指向 `192.168.0.6:58087`）。

日常运维见 [`维护指南.md`](维护指南.md)。
