## 同步上游

```bash
git checkout hubery/dev
git merge upstream/main
npm test && npm run build:node
git push origin hubery/dev
git checkout hubery/main && git merge hubery/dev && git push origin hubery/main
```

## NAS 部署

```bash
cd fork/docker
docker compose -f docker-compose.fork.yml up -d --build
curl -sI http://127.0.0.1:58087/sublink/
```

**端口**：宿主机映射 `58087:8787`；**worker 须在 Docker 默认 bridge**（与 mmw 一致），否则 QNAP 上 NPM 经 `192.168.0.6:58087` hairpin 超时。见 `docs/QNAP部署回顾-2026-06.md` §2。

NPM：见 `fork/docs/npm-server_proxy.snippet.conf`（`proxy_pass http://sublink-worker:8787`，**Docker 容器名**）。

**GitHub 默认分支**：`hubery/main`（与 `hubery/dev` 开发分支配套）。

日常运维见 [`维护指南.md`](维护指南.md)。
